## Patterns Covered (20+)

1. **Two Pointers** - opposite ends, same direction
2. **Sliding Window** - fixed size, variable size
3. **Hash Maps** - frequency counting, O(1) lookup
4. **Prefix Sum** - range queries
5. **Recursion** - base case, recursive case
6. **Tree Traversals** - preorder, inorder, postorder
7. **DFS** - bottom-up, top-down, hybrid
8. **BFS** - level order, shortest path
9. **BST** - search, validation
10. **Backtracking** - subsets, combinations, permutations
11. **Heap** - top K, kth element
12. **Binary Search** - exact match, boundaries, rotated
13. **DP** - 1D, 2D, knapsack variants
14. **Graph Traversal** - connected components
15. **Dijkstra** - weighted shortest path
16. **Topological Sort** - cycle detection, ordering

## Tips for Success

1. **Consistency over intensity** - 60 min daily beats 7 hours weekly
2. **Understand, don't memorize** - Focus on WHY patterns work
3. **Draw it out** - Visualize trees, graphs, recursion
4. **Talk through solutions** - Practice explaining your approach
5. **Review weekly** - Revisit checkpoint days

## FAQ

**Q: What if I can't solve a problem?**
A: Spend 20-25 minutes trying, then look at the solution. Understand it, then re-solve without looking.

**Q: Should I do problems in order?**
A: Yes, days build on each other. Don't skip ahead.

**Q: What language should I use?**
A: Python is recommended for interviews, but use what you're comfortable with.

**Q: How do I know I'm ready for interviews?**
A: When you can solve most mediums in 25 minutes and explain your approach clearly.
