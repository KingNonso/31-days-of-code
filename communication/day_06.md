# Day 6: Simple Language - Clarity Over Complexity

## Overview

**Topic**: Using simple words and short sentences for maximum clarity
**Estimated Time**: 60 minutes
**Difficulty**: Intermediate

## Prerequisites

- Days 1-5 completed
- Email/document samples to simplify
- Willingness to cut jargon

## Time Breakdown

- **Learn (15 min)**: Simplification principles
- **Practice (35 min)**: Rewriting exercises
- **Reflect (10 min)**: Application planning

## Simplification Principles

### The Hemingway Rule

"Write drunk, edit sober" → Speak simply, think deeply

### Complex vs Simple

| Complex     | Simple        |
| ----------- | ------------- |
| Utilize     | Use           |
| Facilitate  | Help          |
| Implement   | Do            |
| Leverage    | Use           |
| Synergize   | Work together |
| Bandwidth   | Time          |
| Circle back | Follow up     |
| Touch base  | Talk          |
| Deep dive   | Analyze       |
| Actionable  | Useful        |

### The 8th Grade Rule

If an 8th grader can't understand it, simplify it.

### Short Sentences Win

- **Long**: "In order to facilitate the successful implementation of the project, we need to leverage our existing resources and synergize our efforts across departments."
- **Short**: "To finish the project, we need to use what we have and work together."

### Task 3: Email Simplification (15 min)

Take a recent work email and:

1. Replace all jargon with simple words
2. Break sentences longer than 15 words
3. Remove unnecessary words
4. Compare word counts: Before **_ → After _**

## Common Pitfalls

- **Sounding "dumb"**: Simple ≠ stupid; simple = clear
- **Industry-specific terms**: Some jargon is necessary; use judiciously
- **Over-simplifying**: Don't lose important nuance
- **Forgetting audience**: Technical audience may need technical terms
