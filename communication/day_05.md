# Day 5: Eliminating Filler Words

## Overview

**Topic**: Replacing verbal fillers with confident pauses
**Estimated Time**: 60 minutes
**Difficulty**: Intermediate

## Prerequisites

- Days 1-4 completed
- Day 2 pause technique practiced
- Recording device for self-analysis

## Time Breakdown

- **Learn (10 min)**: Identify your filler words
- **Practice (40 min)**: Elimination exercises
- **Reflect (10 min)**: Progress tracking

## Common Filler Words

### The Culprits

| Filler    | Impact                         |
| --------- | ------------------------------ |
| Um, uh    | Signals uncertainty            |
| Like      | Undermines credibility         |
| You know  | Assumes shared knowledge       |
| Basically | Minimizes your point           |
| Actually  | Sounds defensive               |
| So...     | Delays getting to the point    |
| Right?    | Seeks validation unnecessarily |
| I mean    | Indicates unclear thinking     |

### Why We Use Fillers

- **Fear of silence**: Filling "awkward" pauses
- **Thinking out loud**: Brain processing
- **Habit**: Unconscious speech patterns
- **Nervousness**: Comfort mechanism

### The Solution: Strategic Silence

Every filler can be replaced with a pause:

- "I think, um, we should..." → "I think [pause] we should..."
- "So basically..." → [Pause] "The key point is..."

## Tasks

### Task 1: Identify Your Fillers (10 min)

Record yourself for 2 minutes on any topic.
Listen back and tally your fillers:

| Filler    | Count |
| --------- | ----- |
| Um/uh     |       |
| Like      |       |
| You know  |       |
| Basically |       |
| So        |       |
| Other:    |       |

**Your top 2 fillers**: ******\_\_\_****** and ******\_\_\_******

### Task 2: Filler Awareness Exercise (15 min)

Have someone (or use an app) buzz you every time you use a filler.

Speak for 3 minutes on:

1. Your morning routine
2. A recent accomplishment
3. Your favorite movie/book

Goal: Reduce fillers with each attempt.

### Task 3: Replacement Practice (15 min)

For your top 2 fillers, practice these replacements:

**If you say "um/uh":**

- Take a breath instead
- Say nothing (embrace the pause)

**If you say "like":**

- Replace with specific comparison: "similar to..."
- Or simply delete it

**If you say "basically":**

- Start with "In short..." or "The key point is..."
- Or just delete it

Record 3 one-minute responses using replacements.

### Task 4: Real Conversation Challenge (10 min)

In your next conversation:

- Focus on ONE filler to eliminate
- Use a physical anchor (touch thumb to finger) when tempted
- Note how many times you caught yourself

## Output Requirements

## Validation

- Did your filler count decrease across recordings?
- Are you more aware of when you use fillers?
- Can you replace fillers with pauses naturally?

## Success Criteria

- [ ] Know your personal filler words
- [ ] Can catch fillers in real-time
- [ ] Practiced replacement techniques
- [ ] Reduced fillers by 50% in practice recordings

## Common Pitfalls

- **Overcorrecting**: Some fillers are natural; aim for reduction, not elimination
- **Sounding robotic**: Pauses should feel natural, not forced
- **Getting frustrated**: This takes weeks to improve, not days
- **Ignoring context**: Casual conversation ≠ presentation
