## Chat Communication Principles

### Async-First Mindset

- Don't expect immediate responses
- Provide complete context in first message
- Reduce back-and-forth

### The Complete Message

Bad: "Hey, got a minute?"
Good: "Hi! Question about the Q3 report: Should we include the competitor analysis section? Context: [brief context]. No rush—EOD is fine."

### Threading Best Practices

- Start threads for topics
- Keep main channel clean
- Reply in thread, not channel

### When to @mention

- **@person**: Need their specific input
- **@here**: Need attention from online people
- **@channel**: Important for everyone
- **No @**: FYI only, no response needed

## Common Pitfalls

- **"Hey" messages**: Always include your actual question
- **Channel pollution**: Use threads
- **Over-@mentioning**: Respect others' attention
- **Expecting instant response**: It's async, not sync
